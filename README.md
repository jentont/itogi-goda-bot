# 🦆 Итоги года — бот + мини-апп

Человек открывает бота, подписывается на спонсоров, держит палец на отпечатке
и листает свои итоги года: живые уточки, снег, бенгальские огни. В конце
выкладывает видео-карточку в историю или отправляет её друзьям. В любом чате
через `@бот` можно отправить свою карточку-картинку «Мои итоги» с главными фактами и кнопкой «Проверить свои итоги».

## Что показывает (всё по-честному)

| Слайд | Откуда данные |
|---|---|
| Сколько дней в Telegram, с какого месяца | оценка по id (как у всех ботов «возраст аккаунта») |
| Premium | данные мини-аппа |
| Подарки: было на 1 января → сейчас, +за год, лучший месяц | `getUserGifts` (подарки в профиле, с датами) |
| Лучший подарок с его живой анимацией (NFT — с цветом фона) | `getUserGifts` + TGS подарка |
| Уровень в Telegram и прогресс до следующего | `getChat → rating` |
| «Ты в Telegram раньше N% людей», сколько часов с Telegram | дата регистрации + официальные цифры аудитории Telegram |
| День рождения: знак, сколько дней осталось, сколько исполнится | `getChat → birthdate` |
| Профиль: аватарки, юзернеймы, статус, канал, «о себе», заполненность в % | `getChat` + `getUserProfilePhotos` |
| Подарки по месяцам, главный даритель, анонимные, с подписью | `getUserGifts` (даты и отправители) |
| Стоимость коллекции в звёздах и ≈ рублях (`STAR_RUB` в .env), NFT, лимитки, редкость NFT | `getUserGifts` |
| Когда и с какого устройства открыты итоги | данные мини-аппа |
| План на следующий год (до 3 целей), через год — «что ты загадал» | база бота |
| Номер среди пользователей, сколько друзей пригласил | база бота |
| 3 номинации года, предсказание на 2027 | выпадают от id (честно поданы как игра) |

Уровень и число подарков сохраняются в базе: в итогах следующего года бот
покажет «был 7 → стал 12».

## Файлы

- `main.py` — запуск (бот + веб-сервер в одном процессе)
- `handlers.py` — /start, проверка подписки, меню, инлайн
- `admin.py` — /admin: спонсоры, статистика, рассылка, пак эмодзи
- `facts.py` — сбор итогов, номинации, предсказания
- `cards.py` — карточка-картинка (JPG) для инлайна и видео (MP4) для историй
- `web.py` — API мини-аппа (проверка подписи Telegram)
- `emoji.py` — свой пак премиум-эмодзи из уточек и расстановка их по кнопкам
- `webapp/` — сам мини-апп (HTML/CSS/JS + lottie)
- `assets/tgs/` — уточки (TGS), `assets/fonts/` — шрифты Unbounded и Manrope (OFL)

## Запуск на сервере

1. Создай бота в @BotFather. Там же:
   - `/setinline` — включи инлайн (плейсхолдер: «Мои итоги года»);
   - `/setinlinefeedback` можно не трогать;
   - `/newapp` или «Main Mini App» — укажи `PUBLIC_URL`, чтобы мини-апп открывался из профиля бота.
2. Скопируй папку на сервер (например в `/opt/itogi`), затем:
   ```bash
   cd /opt/itogi
   python3 -m venv venv && venv/bin/pip install -r requirements.txt
   cp .env.example .env && nano .env
   ```
3. Направь поддомен на сервер, поставь nginx: `deploy/nginx.conf` → `/etc/nginx/sites-enabled/`,
   затем `sudo certbot --nginx -d твой.домен`.
4. Сервис: `deploy/itogi.service` → `/etc/systemd/system/`, затем
   `sudo systemctl enable --now itogi`.
5. Напиши боту `/start`, потом `/admin`:
   - **🦆 Пак эмодзи → Собрать пак** — бот создаст пак `t.me/addemoji/itogi_ducks_by_…`
     из 34 уточек, и они появятся на кнопках и в текстах;
   - **📢 Спонсоры → ➕ Канал** — сделай бота админом канала и перешли сюда пост из него;
   - **➕ Ссылка** — для ботов-спонсоров (их подписку проверить нельзя, просто кнопка).

## Важно про премиум-эмодзи

Telegram показывает кастомные эмодзи у ботов **только если у бота есть юзернейм,
купленный на Fragment**. Без него бот сам откатится на обычные эмодзи — ничего не
сломается. Уточки в мини-аппе и на карточках работают в любом случае.

## Оформление бота в @BotFather

- **Аватарка:** `preview/bot_avatar_640.jpg` → `/setuserpic`. Перерисовать: `cards.avatar(Path(...))`.
- **Картинка описания** («Что умеет этот бот», 640×360): `preview/bot_description_640x360.jpg` →
  Edit Bot → Edit Description Picture. Перерисовать: `cards.about_picture(Path(...))`.
- **Описание и короткое описание** бот ставит себе сам при запуске — тексты в `texts_bot.py`.
- **Баннеры меню и ОП** бот рисует и заливает сам. Перерисовал — поменяй `PROMO_VERSION` в `cards.py`.
- **Кнопка мини-аппа синяя** (`style="primary"`). Если Telegram не пустит премиум-эмодзи, бот снимет
  только иконки — цвет кнопок останется.
